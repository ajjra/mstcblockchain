What is MST Blockchain?

Core network overview

🔗 Layer-1

MST presents its network as a public Layer-1 blockchain for smart contracts, decentralized applications and Web3 services.

⚡ EVM Compatible

EVM compatibility allows developers to work with Solidity contracts and familiar Ethereum-style development tools.

🪙 MSTC

MSTC is the native network asset used for blockchain transactions and network fees.

⛓️ Public Explorer

MSTScan provides public access to blocks, transactions, addresses, tokens and contracts.

🚀 Network Speed

MSTScan currently reports approximately 3 seconds average block time.

🌐 Web3 Infrastructure

The MST ecosystem includes infrastructure and applications for tokenization, NFTs, credentials, gaming, payments and other blockchain use cases.
